# Lecteur réseau inaccessible

**Symptôme :**
L'utilisateur ne peut plus accéder au lecteur réseau partagé.

**Cause :**
Le lecteur réseau n'était plus mappé sur le poste client.

**Résolution :**
Reconnexion du lecteur réseau pointant vers le dossier partagé du serveur.

**Outils :**
GLPI, Explorateur Windows, Windows Server.

**Résultat :**
Accès au partage réseau rétabli.
