# Incidents simulés – GLPI Enterprise Support Lab

Dans le cadre de mon laboratoire personnel orienté support informatique, j'ai entrepris de simuler 9 incidents couramment rencontrés en entreprise afin de développer une méthodologie de diagnostic, de résolution et de documentation.

À ce jour, les incidents suivants ont été simulés et résolus :

* Mot de passe oublié ;
* Lecteur réseau inaccessible ;
* VPN inaccessible ;
* Wi-Fi connecté sans Internet ;
* Fond d'écran GPO non appliqué ;
* Session Windows très lente ;
* Utilisateur supprimé par erreur ;
* Écran noir après connexion ;
* Sauvegarde Windows Server échouée.

Chaque incident est documenté avec :

* le symptôme rencontré ;
* le diagnostic effectué ;
* la cause identifiée ;
* les actions mises en œuvre pour résoudre le problème ;
* les outils utilisés ;
* la vérification du retour à la normale ;
* les enseignements retenus.

Ces simulations ont été réalisées dans un environnement de laboratoire basé sur Windows Server 2019, Active Directory, GPO, VPN RRAS, Windows Server Backup, GLPI et VirtualBox.

L'objectif de ce projet est de me rapprocher des situations réelles rencontrées par les techniciens support IT en entreprise et de constituer un portfolio technique documenté dans le cadre de ma préparation à un premier poste de Technicien Support IT.
