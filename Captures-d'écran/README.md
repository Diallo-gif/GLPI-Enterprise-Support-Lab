# Captures d'écran

Ce dossier contient les captures d'écran du projet GLPI Enterprise Support Lab.

Elles illustrent les différentes étapes du projet :

- Configuration de GLPI
- Gestion des utilisateurs
- Gestion des tickets
- Catégories ITIL
- Support et résolution d'incidents
- Administration de la plateforme

L'objectif est de documenter les actions réalisées dans un environnement simulant un service support IT N1/N2.
